# Hybrid-AI-NWP-Multi-Model-Forecast-Blendig-System
Hybrid AI–NWP Multi-Model Forecast Blending System is an AI-powered weather forecasting platform built for Smart India Hackathon 2026. It intelligently blends multiple Numerical Weather Prediction (NWP) models using adaptive AI weights to generate accurate forecasts for rainfall, temperature, wind, and extreme weather events across India
